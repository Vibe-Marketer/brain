# 33-03: Migrate 2nd-pane Workspace Selector (VIS-02)

## Objective

Replace the inline `<div role="button">` workspace row JSX in `WorkspaceSidebarPane.tsx` (the `WorkspaceListItem` component, ~line 281) with the canonical `<SelectionButton>` primitive. Applies VIS-02.

## Important Constraints

- The workspace row is INSIDE a Collapsible.Root and has a Collapsible.Trigger as a nested button (chevron). The whole row click selects the workspace; the chevron toggles open/closed. With `<SelectionButton>` we need to keep this nested-interactive structure.
- Wrap pattern: `<SelectionButton as="div">` (because of the nested chevron trigger — `<button>` inside `<button>` is invalid HTML). Pass keyboard handler from existing code.
- The workspace icon is `<RiSafeLine className="h-3.5 w-3.5" />` — pass via `icon` prop.
- Currently uses bold-italic + display-font on the name — drop italic, keep bold. This aligns with CONTEXT.md "BOLD title (not bold-italic — that's a separate BRAND-03 issue)". Phase 34 handles BRAND-03; in this plan, the SelectionButton's `font-bold` text already provides bold, no italic.
- The chevron is part of the row but must remain a separate clickable element. Render it as `children` inside `<SelectionButton>` after the default body — OR keep the SelectionButton focused on title+icon+description and lay the chevron next to it. Simplest: render `<SelectionButton as="div">` for the main row, but keep the Collapsible.Trigger chevron as a sibling absolute-positioned element inside.

Actually simpler: render the SelectionButton with the label/icon, and pass the chevron through `children`. But our prop interface doesn't natively show chevron — only `showChevron` (which is the right-arrow). The Collapsible chevron is different (rotates 90°).

Decision: Keep the original `<div role="button">` outer structure but apply SelectionButton **styling tokens** by composing classNames via a helper exported from the SelectionButton file (export the `selectionButtonVariants` cva), so the same orange-pill + ring + bold is applied inline. This is a pragmatic compromise so we don't break the nested-Collapsible chevron behavior.

**Alternative (preferred if feasible):** import the `selectionButtonVariants` cva from selection-button.tsx and apply it to the existing `<div>` row. This keeps one source of truth for the visual classes.
