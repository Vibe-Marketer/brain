## Implementation

### CARD-01 — WorkspaceCard in WorkspaceManagement.tsx

Current (lines 259-303):

```tsx
<Card>
  <CardHeader className="py-3">
    <div className="flex items-center justify-between">
      <div className="flex items-center gap-3">...workspace icon + title...</div>
      <div className="flex items-center gap-2">
        ...delete button...
        <Button
          variant="ghost"
          size="icon"
          aria-label="Open workspace detail"
          onClick={() => openPanel('workspace-detail', { type: 'workspace-detail', workspaceId: workspace.id })}
        >
          <RiArrowRightSLine className="h-4 w-4" />
        </Button>
      </div>
    </div>
  </CardHeader>
</Card>
```

### Edits

1. Make the whole `<Card>` a click target by wrapping it as a `role="button"` div with `tabIndex={0}`, `onClick={openDetail}`, and keyboard support (Enter / Space):

   ```tsx
   const openDetail = () =>
     openPanel('workspace-detail', { type: 'workspace-detail', workspaceId: workspace.id });

   return (
     <>
       <Card
         role="button"
         tabIndex={0}
         onClick={openDetail}
         onKeyDown={(e) => {
           if (e.key === 'Enter' || e.key === ' ') {
             e.preventDefault();
             openDetail();
           }
         }}
         className="cursor-pointer hover:bg-muted/30 focus-visible:ring-2 focus-visible:ring-ring focus-visible:outline-none transition-colors"
         aria-label={`Open ${workspace.name} workspace details`}
       >
         <CardHeader className="py-3">
           <div className="flex items-center justify-between">
             ...workspace icon + title (unchanged)...
             <div className="flex items-center gap-2">
               {canManage && (
                 <Button
                   variant="ghost"
                   size="icon"
                   aria-label="Delete workspace"
                   onClick={(e) => {
                     e.stopPropagation();
                     setDeleteDialogOpen(true);
                   }}
                   className="text-destructive hover:text-destructive hover:bg-destructive/10"
                 >
                   <RiDeleteBinLine className="h-4 w-4" />
                 </Button>
               )}
               <RiArrowRightSLine className="h-4 w-4 text-muted-foreground" aria-hidden="true" />
             </div>
           </div>
         </CardHeader>
       </Card>
       ...delete dialog...
     </>
   );
   ```

2. The chevron stays as a **visual affordance only** (no `<Button>` wrapper, no `onClick`). The delete button gets `e.stopPropagation()` so clicking delete doesn't also open the detail panel.
