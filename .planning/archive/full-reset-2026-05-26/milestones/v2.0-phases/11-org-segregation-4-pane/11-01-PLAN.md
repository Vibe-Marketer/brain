<objective>
Audit and enforce org_id scoping across all service-layer database queries.

Purpose: ORG-01 requires every data query to filter by current org_id. Several services currently query without org_id (import-sources, workspace-entries, recordings detail). ORG-02 requires filter popovers to only show current-org data — some filter data pipelines (tag counts, tag rules) rely on RLS only and need explicit org_id filtering. This plan adds explicit organization_id filtering to every service function that reads data, ensuring zero cross-org leakage.

Output: All service files with explicit org_id filtering on every query; hooks updated to pass orgId from useOrgContext; filter popover data pipelines verified and fixed.
</objective>
