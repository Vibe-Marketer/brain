# Phase 06.3: Obsidian Sync Improvements - Pattern Map

**Created:** 2026-06-10

## Pattern Summary

Phase 06.3 should extend existing export and settings patterns rather than introducing a new integration architecture. The code already has the right high-level pieces: a service fetches export data, a settings component invokes it, and `export-utils.ts` writes files.

## File Map

| Planned Target | Role | Closest Existing Analog | Pattern to Preserve |
|---|---|---|---|
| `src/services/api-tokens.service.ts` | Full-vault export data fetch | `src/services/sync-tab.service.ts`, current `fetchAllCallsForObsidianExport()` | Pure async service functions; no React; Supabase client queries; explicit pagination when full-list behavior matters. |
| `src/lib/export-utils.ts` | Markdown/ZIP generation | Existing `exportToZIP`, `exportToMarkdown`, `exportByFolder`, `exportToObsidian` | Utility functions own file generation and call `saveAs`; keep React out of export utilities. |
| `src/components/settings/ApiTokensSection.tsx` | Primary export UI | Existing token reveal/revoke flow in same file; `MCPTab` settings patterns | Compact settings section, Remix Icons, shadcn buttons, sonner toasts, disabled busy state. |
| `src/components/SmartExportDialog.tsx` | Secondary selected-call export | Existing selected-call export modes | Keep Obsidian as an organization type; do not make it the canonical full-vault path. |
| `src/lib/recording-source-url.ts` | Source/share URL resolution | `CallOverviewTab`, `CallDetailHeader`, `CallTranscriptTab` | Resolve share URLs through helper logic instead of assuming DB column or one metadata key. |
| `src/lib/__tests__/export-utils.obsidian.test.ts` | Export utility tests | Existing `src/lib/__tests__/*.test.ts` | Vitest unit tests with mocked browser/download dependencies. |
| `src/components/settings/__tests__/ApiTokensSection.test.tsx` | UI behavior tests | `src/components/settings/__tests__/IntegrationsTab.test.tsx`, `MCPTab.permissions.test.tsx` | Testing Library with provider mocks; assert visible text and user interactions. |

## Established Constraints

- Service + hook separation is locked. Components should not add direct Supabase export queries.
- `recordings.share_url` is not a top-level column.
- Do not restore `obsidian-sync`.
- Do not add Obsidian-token UI. Use API tokens.
- Do not perform Phase 06.3.2's `legacy_recording_id` rename here.
