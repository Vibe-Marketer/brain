# Phase 16 Plan 02: Admin Center Users Port + Audit Log

## Goal

Ship real, audited user management inside the Admin Center: `/admin/users` lists every platform user with role/plan/last-seen, and a pane-native detail panel performs server-side role changes, password reset, and revoke/restore — all enforced by a new `admin-manage-user` edge function writing to a new append-only `admin_audit_log`. This replaces the unaudited client-side direct-table role editor that lived in Settings AdminTab.

## Source

All ports via `git show worktree-admin-center:<path>`, rebound to live schema. The v2 audit-log posture (admin-read, service-role-write, no client INSERT) is cut from day one.

## Tasks

1. **Create admin_audit_log** — one small idempotent migration: table + admin SELECT via `has_role` + indexes; no client INSERT policy (append-only by design).
2. **Port admin-manage-user edge function** — `rpc('is_admin')` → `rpc('has_role',{_user_id: JWT-verified caller, _role:'ADMIN'})` on the service-role client (immune to grant drift); zod closed action union; audit row on every mutation; password never logged. `verify_jwt=false` in config.toml per the repo-wide ES256 pattern — JWT verified in function code (the dual-client design).
3. **Port Users service + hooks** — `admin-users.service.ts` (avatar_url dropped, not on main), `useAdminUsers.ts` (drop deprecated billing stub; audit invalidation via new queryKey).
4. **Port Users section + detail pane** — `UsersSection.tsx`, `UserProfileDetails.tsx`; recreate the branch's `detailPane` as a local 360px right-hand pane inside AdminCenter (same plane, panelStore-independent to keep admin code out of the main bundle); restore the palette users group; reduce AdminTab to pointer-only and DELETE the now-orphaned `UserTable.tsx` (privilege-escalation footgun).

Security: no-auth 401, invalid JWT 401, non-admin 403, non-admin audit SELECT `[]` (RLS). Probe user cleaned up; append-only audit rows retained by design.
