<objective>
Preserve structured transcript turns at the canonical connector boundary.

Purpose: Provider adapters already create `CanonicalTranscriptTurn` data, but the connector pipeline currently stores only flattened `full_transcript`. This plan extends the canonical contract and shared pipeline so every connector can persist speaker names, emails, offsets, and participant identities once.
</objective>

Add `canonicalTurnsToSegments(turns: CanonicalTranscriptTurn[]): CanonicalTranscriptSegment[]`:
