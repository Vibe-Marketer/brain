    Create two backfill migrations.

    FILE 1 — supabase/migrations/20260609000004_backfill_org_slugs.sql:

    The org backfill must:
    a. Generate base slugs: lower(regexp_replace(name, '[^a-z0-9]', '', 'gi')) truncated to 40 chars. Any org whose name contains only non-alphanumeric characters gets base slug 'org' (fallback — use COALESCE(NULLIF(..., ''), 'org')).
    b. Assign collision suffix: orgs that share the same base slug get rn=1 (no suffix, exactly LEFT(base, 40)), rn=2 gets LEFT(base, 37) || '2', rn=3 gets LEFT(base, 37) || '3', etc. Ordering by created_at ASC so the oldest org keeps the clean slug. The suffix is appended directly (no hyphen — per D-07 slugs are ^[a-z0-9]+$).
    c. Use a single UPDATE ... FROM (CTE) query, not a loop.
    d. After the UPDATE: ALTER TABLE public.organizations ALTER COLUMN slug SET NOT NULL;
    e. After NOT NULL: CREATE UNIQUE INDEX IF NOT EXISTS organizations_slug_unique ON public.organizations(slug);
    f. After the unique index: insert all assigned slugs into org_slug_tombstone so they cannot be re-used if the org is later deleted (pre-populate tombstone). Use: INSERT INTO public.org_slug_tombstone (slug) SELECT slug FROM public.organizations ON CONFLICT (slug) DO NOTHING;
       NOTE: This pre-populates the tombstone with current slugs so the tombstone constraint is retroactively enforced from day 1. This is correct — org_slug_tombstone prevents a slug from being re-assigned after deletion; pre-populating ensures existing slugs are registered.

    The CTE structure (per RESEARCH.md Pattern 4, D-06):
      WITH base_slugs AS (
        SELECT id, COALESCE(NULLIF(lower(regexp_replace(name, '[^a-z0-9]', '', 'gi')), ''), 'org') AS base_slug
        FROM public.organizations WHERE slug IS NULL
      ),
      ranked AS (
        SELECT id, base_slug,
          ROW_NUMBER() OVER (PARTITION BY base_slug ORDER BY created_at ASC) AS rn
        FROM base_slugs
      )
      UPDATE public.organizations o
      SET slug = CASE
        WHEN r.rn = 1 THEN LEFT(r.base_slug, 40)
        ELSE LEFT(r.base_slug, 37) || r.rn::text
      END
      FROM ranked r WHERE o.id = r.id;

    FILE 2 — supabase/migrations/20260609000005_backfill_workspace_slugs.sql:

    Same structure as org backfill but for workspaces. Important difference: workspace slugs must be unique within their org (not globally). The PARTITION BY in the CTE must partition by (base_slug, org_id) so collision counting is per-org:

      WITH base_slugs AS (
        SELECT id, org_id,
          COALESCE(NULLIF(lower(regexp_replace(name, '[^a-z0-9]', '', 'gi')), ''), 'workspace') AS base_slug
        FROM public.workspaces WHERE slug IS NULL
      ),
      ranked AS (
        SELECT id, org_id, base_slug,
          ROW_NUMBER() OVER (PARTITION BY org_id, base_slug ORDER BY created_at ASC) AS rn
        FROM base_slugs
      )
      UPDATE public.workspaces w
      SET slug = CASE
        WHEN r.rn = 1 THEN LEFT(r.base_slug, 40)
        ELSE LEFT(r.base_slug, 37) || r.rn::text
      END
      FROM ranked r WHERE w.id = r.id;

    After UPDATE: ALTER TABLE public.workspaces ALTER COLUMN slug SET NOT NULL;
    After NOT NULL: CREATE UNIQUE INDEX IF NOT EXISTS workspaces_org_slug_unique ON public.workspaces(org_id, slug);
    Pre-populate workspace tombstone: INSERT INTO public.workspace_slug_tombstone (org_id, slug) SELECT org_id, slug FROM public.workspaces ON CONFLICT (org_id, slug) DO NOTHING;
