## Decisions Made

- CREATE TRIGGER statements intentionally deferred to the slug-schema migration (Wave 3). At the time this migration runs, `organizations.slug` and `workspaces.slug` columns do not exist. Postgres errors when you try to create a trigger that references `OLD.slug` on a table that has no `slug` column. The functions are defined here; the triggers are wired in the next migration after `ADD COLUMN slug`.
- `supabase db push --use-api` flag does not exist for `db push` (only for `functions deploy`). Used `supabase db push --linked --include-all` instead. The `--include-all` flag was needed because the migration timestamp (20260609) is ordered before a more recent already-applied migration (20260610).
