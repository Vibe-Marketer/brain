# 06.1-09 Summary: Multi-Org OAuth Grant Ambiguity

## Implemented

- Updated MCP OAuth grant selection to return a `multi_org_ambiguity` error when a user has active grants spanning more than one organization and the MCP request has no explicit workspace or org audience.
- Preserved single-org behavior: multiple grants inside one organization can still resolve without a disambiguation error.
- Updated MCP auth handling to return a 403 JSON response with `error: "multi_org_ambiguity"` and a message directing the user to connect through an org-scoped URL.
- Added regression tests in `supabase/functions/mcp-server/__tests__/oauth-grant-selection.test.ts`.
