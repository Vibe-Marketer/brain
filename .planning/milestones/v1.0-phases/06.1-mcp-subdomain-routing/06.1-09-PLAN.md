<objective>
Fix `supabase/functions/mcp-server/grant-selection.ts` to return 403 with a disambiguation message when a multi-org user hits `mcp.callvaultai.com` (no org slug in URL) and has active grants spanning more than one distinct org.

Purpose: The current `selectOAuthGrant` at line 49 silently returns `grants[0]` when multiple workspace grants exist across different orgs. This means a multi-org user may unknowingly get data from the wrong org. ISC-48–50 (MEDIUM security gate, required before mcp.callvaultai.com picker flow supports multi-org users).

Output: Modified `grant-selection.ts` where `selectOAuthGrant` returns 403 with `{"error": "multi_org_ambiguity", "message": "Use org-scoped URL: orgslug.callvaultai.com/mcp"}` on multi-org ambiguity.
</objective>
