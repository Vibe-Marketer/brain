<objective>
Add `x-callvault-internal-secret` header validation as the FIRST action in all three MCP Edge Functions: `mcp-server` (via auth.ts), `mcp-oauth-register/index.ts`, and `mcp-oauth-metadata/index.ts`. Generate and set the secret in both Cloudflare Worker env vars and Supabase secrets.

Purpose: Cloudflare Workers can be bypassed by hitting the Supabase project URL directly (`<project>.supabase.co/functions/v1/mcp-server`). Without a shared secret, the Worker's slug injection and IP allowlist provide zero protection. This is ISC-1–7 (CRITICAL security gate) and a prerequisite for sec-enumeration (Wave 2) and the new subdomain Worker (Wave 4).

Output: All three MCP Edge Functions reject requests missing the correct internal secret header with 403 before any other processing.
</objective>
