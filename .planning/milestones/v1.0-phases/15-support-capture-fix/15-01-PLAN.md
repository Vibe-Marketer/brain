## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user browser → storage.objects | reporter uploads under own JWT; storage RLS is the enforcement layer |
| user browser → send-support-ticket | attachment path references cross into the Edge Function |
| screenshot content → Storage | the captured page may contain sensitive call data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Spoofing / Information Disclosure | attachments[].path in function payload | mitigate | Edge Function rejects any path not prefixed `${userId}/` (Task 2); paths come from the JWT-derived prefix in the service (Task 3) |
| T-15-02 | Tampering | uploads outside own folder | mitigate | storage.objects INSERT policy `(storage.foldername(name))[1] = auth.uid()::text` (Task 2) |
| T-15-03 | Information Disclosure | screenshot of sensitive page content | mitigate | bucket private; SELECT policy owner-or-ADMIN only; no public URLs anywhere in this plan |
| T-15-04 | Denial of Service | oversized/hostile uploads | mitigate | bucket file_size_limit 5MB + allowed_mime_types allowlist (Task 2) |
| T-15-SC | Tampering | package installs | accept | No package installs this plan — slopcheck gate not applicable |
</threat_model>
