<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| MCP params -> workspace mutation | Client-supplied workspace/org values must not override token/path authority |
| MCP params -> connector pipeline | Already-transcribed user content becomes a CallVault recording row |
| Primary ingest -> enrichments | Non-critical metadata writes must not hide failures or roll back the primary recording |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-02-01 | Elevation of Privilege | target workspace resolution | mitigate | Resolve workspace from token/path first and reject mismatches before mutation. |
| T-04-02-02 | Tampering | source metadata | mitigate | Preserve Manual MCP Import as visible identity and confine client/original URL details to `source_metadata`. |
| T-04-02-03 | Denial of Service | transcript payload | mitigate | Validate bounded string/list sizes before `runPipeline()`. |
| T-04-02-04 | Repudiation | enrichment warnings | mitigate | Return markdown created/reused/warning breakdown for every non-critical step. |
</threat_model>
