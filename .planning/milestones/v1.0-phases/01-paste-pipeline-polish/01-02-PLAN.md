<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user -> PasteTranscriptModal | The UI accepts untrusted transcript text, transcript files, and source metadata |
| PasteTranscriptModal -> save-pasted-transcript | The modal packages transcript content and workspace/org identifiers for the backend |
| mutation success -> query cache | Post-import cache invalidation determines whether the UI reflects the saved record or stale data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Tampering | Transcript file chooser affordances | mitigate | Restrict visible upload affordances to transcript text formats per D-08 so the UI does not invite unsupported audio/video inputs. |
| T-01-07 | Information Disclosure | Inline error copy | mitigate | Keep errors friendly but scoped to dedup/permission/parse outcomes without exposing stack traces or backend internals. |
| T-01-08 | Denial of Service | Stale cache after import | mitigate | Route success handling through `invalidateCallListCaches(queryClient)` so imports do not appear lost because the UI stayed stale. |
| T-01-09 | Spoofing | User perception of import mode | mitigate | Use D-11 `Import Transcript` language consistently so the user is not misled into believing audio/video transcription is available in Phase 1. |
</threat_model>
