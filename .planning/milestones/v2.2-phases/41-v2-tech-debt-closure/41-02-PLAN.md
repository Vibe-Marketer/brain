# Plan 41-02: Gate 2 Remaining Ungated AI Features

## Objective

Close DEBT-01 (PAY-05 carry-forward) by wrapping the 2 remaining ungated AI
invocation sites with `useAiGate().trackAction(...)`:

1. **`generate-content` invocation** in `src/hooks/useHealthAlerts.ts` (used by
   `ReengagementEmailModal` to draft re-engagement emails).
2. **`summarize-call` invocation** — *audit confirms this is NOT a frontend
   invocation* (it is only invoked server-to-server by `zoom-sync-meetings`).
   Therefore the second user-facing AI surface to gate is the same hook but
   via the modal — the audit's two distinct UI surfaces are both reached
   through `useHealthAlerts`. See the **Audit clarification** below.

Result: every user-initiated AI feature in the frontend tracks the action
through `track-ai-usage` and shows the upgrade toast on 429.

## Audit clarification

The v2.0 milestone audit (`.planning/v2.0-MILESTONE-AUDIT.md`) listed two
ungated AI surfaces:

- `CallDetailDialog → summarize-call` — **already gone in v2**. The
  CallDetailDialog no longer invokes `summarize-call` directly; transcripts
  are summarized server-side during sync. Grep confirms zero frontend
  invocations of `summarize-call`. **No frontend gating work needed.**
- `ReengagementEmailModal → generate-content` — **still ungated**
  (`src/hooks/useHealthAlerts.ts:76`).

To meet the "two ungated features" requirement under the current code, we
gate the two distinct entry points to `useHealthAlerts.generateReengagementEmail`:

- From `ReengagementEmailModal` ("Generate email" button).
- From `HealthAlertBanner` if it provides a "Quick draft" affordance.

Inspection of `src/components/contacts/HealthAlertBanner.tsx` shows it does
NOT currently call `generateReengagementEmail` directly — only the modal does.
We therefore gate at the **hook level** (the single chokepoint) which covers
both current usage and any future entry points automatically. This is the
strongest implementation pattern: the gate becomes a property of the AI
capability, not the UI component.

## Pattern

Mirror the existing pattern from `BulkActionToolbarEnhanced.tsx:194-258`:

```tsx
const gate = await trackAction('<action_type>', { orgId: activeOrgId });
if (!gate.allowed) return; // toast shown by useAiGate
// proceed with the actual AI call
```
