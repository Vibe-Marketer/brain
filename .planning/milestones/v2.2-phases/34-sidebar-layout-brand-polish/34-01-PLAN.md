# 34-01 — Replace Sidebar Emoji Icons with Remix Icons

**Priority:** CRITICAL — fixes HARD-CONSTRAINT violation (`src/CLAUDE.md`: "Remix Icons ONLY — no Lucide, FontAwesome, or others").

## Background

`src/components/ui/sidebar-nav.tsx` currently renders emoji glyphs (`📞 👥 🏢 📥 🔀 ❓ ℹ️ ⚙️`) wrapped in `<span role="img">`. The file already imports the correct Remix Icons (`RiPhoneLine`, `RiGroupLine`, etc.) and defines `icon` + `iconActive` on each `NavItem`, but the body renders `emojiIcon` (a span of the emoji string) instead. Fix is mechanical: render the actual icon components.
