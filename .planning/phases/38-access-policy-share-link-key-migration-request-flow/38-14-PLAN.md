- Assets: anonymous copy identity, request UUID, owner-only requester evidence, notification metadata, authenticated return URL.
- Boundaries: discovery RPC response to DOM; notification JSON metadata to navigation; URL query to owner management fetch/focus.

| Threat ID | Category | Severity | Threat | Mitigation | Verification |

| T-38-14-01 | Information disclosure | CRITICAL | Protected copy fields enter DOM/URL/logs | Minimal type/RPC, no broad props, forbidden-field tests | Component + Playwright network/DOM checks |
| T-38-14-02 | Spoofing | HIGH | Forged notification opens another request | Strict metadata/UUID validation and owner-authorized fetch | Invalid/non-owner tests |
| T-38-14-03 | Information disclosure | HIGH | Large/webinar/unknown-signal hidden state is revealed by UI | Render nothing unless server returns eligible rows | 49/50/provider-aggregation tests |
| T-38-14-04 | Tampering | MEDIUM | Deep link loses/changes request ID | Query-preserving controlled pipeline and validation | E2E deep-link test |
| T-38-14-SC | Tampering | LOW | New routing/UI dependency | Existing router/primitives only | Lockfile diff |
</threat_model>
