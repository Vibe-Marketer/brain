<threat_model>
## Assets and trust boundaries

- Assets: verified email/evidence, recording content, share tokens, public content allowlist, and deep-link request identifiers.
- Boundaries: browser to Edge Function/RPC, MCP input to tool module, notification metadata to router, public anonymous request to content response.

| Threat ID | Category | Severity | Threat | Mitigation | Verification |
|---|---|---:|---|---|---|
| T-38-03-01 | Spoofing | HIGH | Client supplies owner/requester identity or evidence | Request-ID-only API; server loads all trusted values after auth | Edge integration tests with forged fields |
| T-38-03-02 | Information disclosure | HIGH | Public or anonymous-copy response leaks raw recording fields | Exact response allowlists and generic not-available errors | Forbidden-key API/DOM assertions |
| T-38-03-03 | Tampering | HIGH | Deep link opens another owner's request | Owner-authorized fetch after navigation; generic unavailable result | Component and Playwright non-owner test |
| T-38-03-04 | Denial of service | MEDIUM | Retries send duplicate email | Unique outbox idempotency key and stable retry behavior | Repeated-invocation integration test |
| T-38-03-SC | Tampering | LOW | UI dependency introduces banned package/icons | Existing shadcn/Remix only; no installs | Lockfile and banned-import scan |
</threat_model>
