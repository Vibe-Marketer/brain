## Assets and trust boundaries

- Assets: requester verified email/evidence, owner email, meeting title/date, request/grant state, notification/outbox.
- Boundaries: browser request ID to Edge; authenticated JWT to service-role read; RPC result to role-specific TypeScript shapes; Resend provider response to outbox.

| Threat ID | Category | Severity | Threat | Mitigation | Verification |
|---|---|---:|---|---|---|
| T-38-11-01 | Spoofing | HIGH | Browser supplies another identity/owner/email/evidence | Request-ID-only schema and server-side trusted loads | Forged-field/non-party tests |
| T-38-11-02 | Information disclosure | HIGH | Requester-safe type leaks owner/content/evidence | Separate minimal type with forbidden-field source/test checks | Component/type assertions |
| T-38-11-03 | Denial of service | HIGH | Retry sends duplicate email | Unique outbox key and claim/sent state | Concurrent retry integration test |
| T-38-11-04 | Information disclosure | HIGH | HTML/log injection exposes PII | escapeHtml and generic bounded logs | Escaping/log assertions |
| T-38-11-05 | Tampering | HIGH | Test email function deploy targets production | Double test-ref check and final relink | Evidence record |
| T-38-11-SC | Tampering | LOW | Package install changes Edge runtime | Existing Zod/Resend HTTP only; no install | Lockfile diff |
