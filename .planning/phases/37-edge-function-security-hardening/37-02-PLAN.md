<action>
Refactor `polar-webhook/index.ts` to add a single `upsertSubscription(supabase, userId, status, subscription)` helper that replaces both `handleSubscriptionCreated` and `handleSubscriptionActive` payload-update branches.

Specifically:
- Add new function with signature `async function upsertSubscription(supabase, userId, status: string, subscription: { id: string; productId: string; currentPeriodEnd: string | Date })`.
- Inside it: do the `from('user_profiles').update({ subscription_id, subscription_status: status, product_id, current_period_end }).eq('user_id', userId)` call.
- `handleSubscriptionCreated` calls `upsertSubscription(supabase, userId, subscription.status, subscription)` — status comes from the subscription payload.
- `handleSubscriptionActive` calls `upsertSubscription(supabase, userId, 'active', subscription)` — status hard-coded.
- Both handlers also call `provisionMcpTokenForUser` after the upsert via the wait-until wrapper introduced in T02.

Preserve the existing comments explaining D-02 and externalId fallback.
