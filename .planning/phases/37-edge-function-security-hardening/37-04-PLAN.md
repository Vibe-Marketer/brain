# Plan 37-04: Encrypt Existing Plaintext OAuth Tokens

## Objective

The encryption infrastructure (RPCs, helpers) shipped in migration `20260509000001_oauth_token_encryption_helpers.sql`. New OAuth flows write encrypted tokens. **But existing rows from before that migration are still plaintext.** This plan writes a one-shot migration that encrypts every plaintext row in `import_sources` and `user_settings` if `OAUTH_ENCRYPTION_KEY` is set, with a verifiable count before/after.

```sql
-- Migration: Encrypt existing plaintext OAuth tokens
-- Purpose: Convert plaintext OAuth tokens in import_sources and user_settings
--          to PGP-armored ciphertext using the encryption key from
--          OAUTH_ENCRYPTION_KEY Supabase secret (passed via app setting).
--          IDEMPOTENT — re-running is safe (skips rows whose tokens look
--          already-armored, marked by the "-----BEGIN PGP MESSAGE-----" header).
-- Author: Phase 37 Security Hardening
-- Date: 2026-05-12

-- ============================================================================
-- FUNCTION: encrypt_existing_oauth_tokens(p_key TEXT)
-- ============================================================================
-- Encrypts plaintext OAuth tokens in-place. Skips rows already encrypted
-- (those whose value starts with the PGP armor header).
-- Returns a count summary as JSON.
CREATE OR REPLACE FUNCTION encrypt_existing_oauth_tokens(p_key TEXT)
RETURNS JSON
LANGUAGE plpgsql SECURITY DEFINER
AS $$
DECLARE
  v_import_sources_count INT := 0;
  v_user_settings_count  INT := 0;
BEGIN
  -- import_sources
  UPDATE import_sources
  SET
    oauth_access_token  = encrypt_token(oauth_access_token,  p_key),
    oauth_refresh_token = encrypt_token(oauth_refresh_token, p_key)
  WHERE
    (oauth_access_token IS NOT NULL  AND oauth_access_token  NOT LIKE '-----BEGIN PGP MESSAGE-----%')
    OR (oauth_refresh_token IS NOT NULL AND oauth_refresh_token NOT LIKE '-----BEGIN PGP MESSAGE-----%');

  GET DIAGNOSTICS v_import_sources_count = ROW_COUNT;

  -- user_settings
  UPDATE user_settings
  SET
    oauth_access_token  = encrypt_token(oauth_access_token,  p_key),
    oauth_refresh_token = encrypt_token(oauth_refresh_token, p_key)
  WHERE
    (oauth_access_token IS NOT NULL  AND oauth_access_token  NOT LIKE '-----BEGIN PGP MESSAGE-----%')
    OR (oauth_refresh_token IS NOT NULL AND oauth_refresh_token NOT LIKE '-----BEGIN PGP MESSAGE-----%');

  GET DIAGNOSTICS v_user_settings_count = ROW_COUNT;

  RETURN json_build_object(
    'import_sources_encrypted', v_import_sources_count,
    'user_settings_encrypted',  v_user_settings_count
  );
END;
$$;

COMMENT ON FUNCTION encrypt_existing_oauth_tokens IS 'One-shot encryption migration. Run manually after deploy with: SELECT encrypt_existing_oauth_tokens(''<OAUTH_ENCRYPTION_KEY_value>'');';

-- ============================================================================
-- AUDIT VIEW: oauth_token_encryption_status
-- ============================================================================
-- Shows count of plaintext-vs-encrypted token rows for ops visibility.
CREATE OR REPLACE VIEW oauth_token_encryption_status AS
SELECT
  'import_sources'::TEXT AS table_name,
  COUNT(*) FILTER (
    WHERE (oauth_access_token  IS NOT NULL AND oauth_access_token  NOT LIKE '-----BEGIN PGP MESSAGE-----%')
       OR (oauth_refresh_token IS NOT NULL AND oauth_refresh_token NOT LIKE '-----BEGIN PGP MESSAGE-----%')
  ) AS plaintext_rows,
  COUNT(*) FILTER (
    WHERE oauth_access_token LIKE '-----BEGIN PGP MESSAGE-----%'
       OR oauth_refresh_token LIKE '-----BEGIN PGP MESSAGE-----%'
  ) AS encrypted_rows,
  COUNT(*) AS total_rows
FROM import_sources
UNION ALL
SELECT
  'user_settings'::TEXT AS table_name,
  COUNT(*) FILTER (
    WHERE (oauth_access_token  IS NOT NULL AND oauth_access_token  NOT LIKE '-----BEGIN PGP MESSAGE-----%')
       OR (oauth_refresh_token IS NOT NULL AND oauth_refresh_token NOT LIKE '-----BEGIN PGP MESSAGE-----%')
  ) AS plaintext_rows,
  COUNT(*) FILTER (
    WHERE oauth_access_token LIKE '-----BEGIN PGP MESSAGE-----%'
       OR oauth_refresh_token LIKE '-----BEGIN PGP MESSAGE-----%'
  ) AS encrypted_rows,
  COUNT(*) AS total_rows
FROM user_settings;

COMMENT ON VIEW oauth_token_encryption_status IS 'Ops visibility into OAuth token encryption state. Used by Phase 37 verification.';

-- ============================================================================
-- END OF MIGRATION
-- ============================================================================
```

NOTE: The actual encryption RUN is performed manually by ops via `SELECT encrypt_existing_oauth_tokens('<key>');`. The migration installs the function + audit view; it does NOT run the encryption (since the key isn't in the DB).

Document the run procedure in plan SUMMARY.md.
