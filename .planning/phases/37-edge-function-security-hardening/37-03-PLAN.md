# Plan 37-03: Shared-Auth Migration

## Objective

Replace the brittle `authHeader.replace('Bearer ', '')` pattern with `_shared/auth.ts authenticateRequest()` in every function that uses user-JWT authentication. Exempt list (skip):

- `polar-webhook` (Svix signature)
- `zoom-webhook` (Zoom HMAC)
- `webhook` (legacy public)
- `mcp-oauth-metadata` / `mcp-oauth-register` (no JWT)
- `teams` and `fetch-single-meeting` (no `authHeader.replace` in current source — investigate)
- `mcp-server` (custom MCP OAuth — investigate but likely exempt)
- `zoom-oauth-callback` (code-exchange — JWT may not be present yet)
- `create-fathom-webhook` (verify whether user-JWT or server-side)

## Tasks

<task id="37-03-T01">
<action>
For EACH of the 24 target functions listed in `files_modified` above (excluding the 3 ambiguous ones — `mcp-server`, `zoom-oauth-callback`, `create-fathom-webhook` — which are handled in T02):

1. Add `import { authenticateRequest } from '../_shared/auth.ts';` near the top.
2. Replace the block:
   ```ts
   const authHeader = req.headers.get('Authorization');
   if (!authHeader) { ...401... }
   const token = authHeader.replace('Bearer ', '');
   const { data: { user }, error: userError } = await supabase.auth.getUser(token);
   if (userError || !user) { ...401... }
   ```
   With:
   ```ts
   const authResult = await authenticateRequest(req, supabase, corsHeaders);
   if (authResult instanceof Response) return authResult;
   const userId = authResult.userId;
   ```
3. Replace every downstream `user.id` reference with `userId`. (Use Edit `replace_all=true` per file.)
4. Preserve all other behavior (Zod validation, ownership checks, business logic).

Do them in alphabetical order. Each function is its own atomic edit; do NOT batch into one commit — commit will be batched per SEC-02A in the executor's final wrap.
</action>
