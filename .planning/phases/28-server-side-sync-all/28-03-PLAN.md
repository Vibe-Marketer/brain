<interfaces>
Every provider implements: (params: ListPageParams) => Promise<ListPageResult<ProviderItem>>
  ListPageParams = { accessToken, cursor: string|null, dateStart: string|null, dateEnd: string|null }
  ListPageResult = { items: ProviderItem[], nextCursor: string|null }   // null = exhausted

Cursor encoding per provider (opaque to the pager):
  Fathom / Grain : provider's next_cursor / cursor token verbatim
  Zoom           : JSON-encoded { window_from, window_to, next_page_token } — advance window when a window's pages exhaust; null only after the final window's final page
  Read.ai        : last item id; null when has_more is false (limit clamped to 10)
  Fireflies      : String(skip); null when a page returns fewer than limit (50)
  Plaud          : String(skip); null when a page returns fewer than page_size; date filtered post-fetch via isWithinDateRange
</interfaces>
