<interfaces>
The uniform contract this plan creates (the pager and all providers depend on it):

ListPageResult<T>: { items: T[]; nextCursor: string | null }
ListPageParams: { accessToken: string; cursor: string | null; dateStart: string | null; dateEnd: string | null }
ListPageFn<T>: (params: ListPageParams) => Promise<ListPageResult<T>>

nextCursor is an OPAQUE string the pager stores in sync_jobs.provider_cursor and passes back verbatim. Each provider encodes its own dialect inside it: Fathom/Grain opaque token; Zoom composite {window_from, window_to, next_page_token}; Read.ai last-item id; Fireflies/Plaud offset (skip as string). nextCursor === null means exhausted.
</interfaces>
