Function body:
       - `INSERT INTO public.tickets (reporter_id, type, severity, status, source, fingerprint, context, occurrence_count, last_seen_at) VALUES (NULL, 'bug', p_severity, 'new', 'sentry', p_fingerprint, p_context, 1, NOW()) ON CONFLICT (fingerprint) WHERE fingerprint IS NOT NULL DO UPDATE SET occurrence_count = tickets.occurrence_count + 1, last_seen_at = NOW() RETURNING id, tickets.occurrence_count INTO ...` — created = (returned occurrence_count = 1).

    4. `REVOKE ALL ON FUNCTION public.ingest_sentry_ticket FROM PUBLIC, anon, authenticated;` — service-role-only entry point; the Edge Function calls it via the service-role client.
