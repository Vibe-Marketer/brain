## Layout & Interaction Contract

- **Focal point:** the tickets table is the primary visual anchor of the section; the `New Ticket` button (section header, right-aligned) is the single action anchor. In the detail dialog, the status + severity badge row is the focal point. Icon-only elements always carry an accessible label (`aria-label` or visible text) — no icon-only buttons without labels.
- **Placement:** new `Tickets` section inside `AdminTab.tsx`, between System Overview and User Management, replacing the deleted Feature Flags section slot (FLAG-01). Same section idiom: heading block → `space-y-4` → `<Separator className="my-16" />`.
- **Filters row:** mirrors User Management filters — search-less; three `Select` filters (Status / Severity / Source) at `sm:w-40` each, with `Label` above and `mt-2` on trigger. "All" option first in each (`All Statuses`, `All Severities`, `All Sources`).
- **Table:** use `src/components/ui/table.tsx` (mirror `UserTable` structure — extract a `TicketTable` component in `src/components/settings/`). Columns: Type (icon + label), Summary (first message, truncated), Severity (StatusBadge), Status (StatusBadge), Source (`manual`/`sentry` as muted text), Reporter, Created (date-fns relative, `text-xs text-muted-foreground`, `tabular-nums`). Row click opens detail.
- **Detail view (Claude's-discretion area — locked here):** Radix `Dialog` at `sm:max-w-2xl` (matches `dialogs/` idiom; settings tab has no pane-4 slot). Contents top-to-bottom: header (type + short id, status + severity badges), context block (captured URL, app version, user agent in `text-xs` definition list), messages, then `Activity` event timeline — vertically stacked `text-xs` rows: dot marker + event description + relative timestamp, newest first, sourced from `ticket_events` (TKT-04). Status-change `Select` in the header for admin transitions.
- **Loading:** centered `RiLoader2Line` spinner `h-6 w-6 animate-spin text-muted-foreground` in `py-12` (AdminTab idiom).
- **Empty state:** centered icon (`RiTicketLine` or `RiCustomerService2Line`, `h-12 w-12 text-muted-foreground`) over copy, inside `border border-dashed border-border rounded-xl py-12` container.
- **Access gating:** entire section renders only for `isAdmin` (already enforced at AdminTab top via `useUserRole`).
- **Data layer:** service + hook pattern — `src/services/tickets.service.ts` (pure async) + `src/hooks/useTickets.ts` (TanStack Query). No direct supabase calls in the component (improves on legacy AdminTab inline queries; locked project pattern wins).
- **Flag removal (FLAG-01):** delete Feature Flags section, `FeatureFlag` interface, `loadFeatureFlags`, `handleToggleFlag`, `Switch` import if unused; remove gates in `Layout.tsx` / `sidebar-nav.tsx`; delete `useFeatureFlags`. No replacement UI.
