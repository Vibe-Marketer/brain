  <action>
    Two issues to fix:

    **Issue A — Connect buttons navigate away, closing the wizard (ONBOARD-02):**

    In OnboardingModal.tsx Step 1 (stepConnect), the three SourceCard onAction callbacks use `navigate()` which navigates away from the current page, causing the Dialog to unmount and the handleOpenChange to fire with `nextOpen=false`, which calls `handleFinish()` and marks onboarding complete prematurely.

    Fix the connect button actions:
    - **Fathom:** Change `navigate("/settings?tab=integrations&wizard=fathom")` to `window.open("/settings?tab=integrations&wizard=fathom", "_blank")` — opens in new tab so wizard stays open. User can complete OAuth in the new tab and come back.
    - **Zoom:** Change `navigate("/settings?tab=integrations")` to `window.open("/settings?tab=integrations", "_blank")` — same pattern.
    - **Upload:** Change `navigate("/import")` to `window.open("/import", "_blank")` — same pattern.
    - Update the actionLabel for each to hint at the new-tab behavior: keep labels as-is ("Connect Fathom", "Connect Zoom", "Upload file") — the window.open behavior is self-explanatory.
    - After each SourceCard, the user returns to the wizard tab. The "I'll do this later" link at the bottom already advances to step 2, which is correct.

    **Issue B — Post-completion navigation (ONBOARD-03):**

    In Layout.tsx, when onboarding completes (OnboardingModal calls onComplete), the user stays on whatever page they were on. For a new user this is `/` which is correct (TranscriptsNew with 4-pane layout). However, if somehow they ended up on another page, we should ensure they land at `/`.

    Fix in Layout.tsx:
    - Import `useNavigate` from react-router-dom
    - Create a wrapper around completeOnboarding that also navigates:
      ```typescript
      const navigate = useNavigate();
      const handleOnboardingComplete = async () => {
        await completeOnboarding();
        navigate('/');
      };
      ```
    - Pass `handleOnboardingComplete` to OnboardingModal's `onComplete` prop instead of `completeOnboarding` directly.

    Also remove the `useNavigate` import from OnboardingModal.tsx since it no longer uses navigate (the window.open calls don't need it). Remove the `const navigate = useNavigate();` line from the component.
  </action>
