## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| database source enum -> operator UI | Raw machine values cross into visible admin text if not humanized |
| operator controls -> ticket query filters | UI-selected source values drive service filters but must not edit ticket source |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-12 | Information Disclosure | `ticketSourceLabel()` | mitigate | Return only locked labels; unknown/unrecognized values become "Unknown source". |
| T-18-13 | Spoofing | Tickets UI source controls | mitigate | Controls filter only; no source edit affordance exists in TicketTable or detail views. |
| T-18-14 | Denial of Service | group-by-source rendering | mitigate | Group only loaded page rows; preserve bounded ticket pagination. |
| T-18-SC | Tampering | npm installs | accept | No package installs are planned; Remix Icons only if icons are used. |
</threat_model>
