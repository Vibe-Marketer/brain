# 34-03 — UPPERCASE Primary Titles

Per CONTEXT.md / REQUIREMENTS.md BRAND-02: every primary title in sidebar AND 2nd pane is UPPERCASE: `CALLS, PEOPLE, ORGANIZATION, IMPORT, RULES, NAVIGATION, MY CALLS, YOUR WORKSPACES, SHARED WITH ME` etc.

The data labels (`name: 'Calls'` etc.) in `navItems` are display strings rendered by `<SelectionButton>` via the `label` prop. `SelectionButton`'s `labelVariants` (selection-button.tsx line 117-130) does NOT auto-uppercase — it just sets font weight. So we must either:

(a) uppercase the source strings, or
(b) add `uppercase` Tailwind class on the rendered label.

Per CONTEXT.md the value should look UPPERCASE in DOM. Cleanest is option (b) — add `uppercase tracking-tight` to the label rendering via a wrapper. But SelectionButton owns the rendering. Pragmatic: change the source `name` strings to UPPERCASE in `sidebar-nav.tsx` AND verify the 2nd-pane component headings already use `uppercase` class (per inspection most do — `text-[10px] font-black uppercase tracking-[0.2em]` is the pattern).
