# 34-05 — Workspace 2nd-Pane Polish

- **BRAND-03** — Workspace title is BOLD ONLY (currently `font-display italic`). Remove `italic` and `font-display` from the active-state workspace label.

- **BRAND-05** — Top-bar org selector width matches the 2nd-pane org box width.
- **BRAND-06** — "ALL" badge in Home button is dark enough to read. Change `bg-cb-border/30` (light) to `text-foreground bg-muted` for legibility.
