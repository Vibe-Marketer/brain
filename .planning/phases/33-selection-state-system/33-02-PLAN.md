# 33-02: Migrate Sidebar Nav to SelectionButton (VIS-01)

## Objective

Replace the inline selection-state JSX/classes in `src/components/ui/sidebar-nav.tsx` with the canonical `<SelectionButton>` primitive built in 33-01. This applies VIS-01.

## Important Constraints

- The current sidebar uses **emoji icons** for nav items (e.g., `📞` for Calls). Preserve that — wrap the emoji span in the icon slot of `<SelectionButton>`. Phase 34 (BRAND polish) will likely revisit emoji→Remix-icon migration; keep emojis for now.
- Sidebar has TWO modes: expanded and collapsed (`isCollapsed`). The canonical pattern only applies in expanded mode. In collapsed mode (icon-only rail), keep the existing pill + icon styling but route through `<SelectionButton>` if practical, OR keep an inline collapsed-only variant. **Decision:** keep `<SelectionButton>` for expanded; render a minimal collapsed button inline (since collapsed has no label/description to render).
- Sidebar contains Settings (bottom-pinned) + Take the Tour + How it Works buttons. The Settings nav row should use `<SelectionButton>`; the other two are not "selection" items (they trigger actions, never selected) — leave as plain buttons OR convert to a non-selectable variant. Decision: leave Tour/HowItWorks as plain buttons.
