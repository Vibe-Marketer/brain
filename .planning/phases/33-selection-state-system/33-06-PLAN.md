# 33-06: Replace Org-Tab Strip with Canonical Card List (VIS-05)

## Objective

In `src/components/settings/OrganizationsTab.tsx`, replace the horizontal Radix `<Tabs>` strip (lines ~69-149 — currently renders "AI SIMPLE | BUSINESS | GOVIBEY" as horizontal tabs) with a **vertical list of canonical-selection cards** matching the locked CONTEXT.md decision.

The selected org's full detail content (org name card, workspaces management, etc.) renders BELOW the card list — or, optionally, beside it in a 2-column layout. **Decision (per CONTEXT.md):** vertical list of cards in the secondary pane; selected org renders in the main pane. But `OrganizationsTab.tsx` is rendered INSIDE the Settings detail pane (3rd pane) — there's no "2nd pane" inside this tab. So: render the org-list as a vertical card list on the LEFT of the tab content, and the selected org's detail content on the RIGHT.

Simpler: render as a vertical list at the top, with the selected org's content below. This is the "tab strip replaced with vertical list" interpretation, and aligns with how settings sub-panes work elsewhere.

**Final decision:** vertical card list at the top of the tab content; selected org's detail card + WorkspaceManagement below it. Single-column flow.

```tsx
const [selectedOrgId, setSelectedOrgId] = useState<string>(defaultOrgId);
const selectedOrg = organizations.find((o) => o.id === selectedOrgId) ?? organizations[0];

return (
  <div className="space-y-6">
    {/* Header — keep existing */}
    <div>
      <h2 className="text-2xl font-bold">Workspaces</h2>
      <p className="text-muted-foreground">Manage your organizational structure and collaboration workspaces</p>
    </div>

    {/* Vertical card list of orgs — canonical SelectionButton */}
    <div className="flex flex-col gap-1 max-w-2xl">
      {organizations.map((org) => {
        const memberCount = org.member_count ?? 1;
        const role = (org.membership?.role || 'member').replace('organization_', '');
        const description = `${memberCount} member${memberCount === 1 ? '' : 's'} · ${role}`;
        return (
          <SelectionButton
            key={org.id}
            selected={selectedOrgId === org.id}
            icon={org.type === 'personal' ? <RiUserLine className="h-4 w-4" /> : <RiBuilding4Line className="h-4 w-4" />}
            label={org.name}
            description={description}
            size="md"
            onClick={() => setSelectedOrgId(org.id)}
          />
        );
      })}
    </div>

    {/* Selected org detail content */}
    {selectedOrg && (
      <div className="space-y-6">
        {/* Org details card — KEEP existing CardHeader/CardContent block, just inline it */}
        <Card>
          <CardHeader>
            <div className="flex items-center justify-between">
              <div>
                <CardTitle>{selectedOrg.name}</CardTitle>
                <CardDescription>
                  {selectedOrg.type === 'personal'
                    ? 'Your personal organization for private recordings'
                    : 'Business organization for team collaboration'}
                </CardDescription>
              </div>
              <div className="flex items-center gap-2">
                <Badge variant="outline" className="capitalize">{selectedOrg.type}</Badge>
                <Badge variant="secondary" className="capitalize">
                  {(selectedOrg.membership?.role || 'member').replace('organization_', '')}
                </Badge>
                {selectedOrg.type === 'business' && selectedOrg.membership?.role === 'organization_owner' && (
                  <Button
                    variant="ghost"
                    size="icon"
                    aria-label="Delete organization"
                    onClick={() => setDeletingOrg(selectedOrg)}
                    className="text-destructive hover:text-destructive hover:bg-destructive/10"
                  >
                    <RiDeleteBinLine className="h-4 w-4" />
                  </Button>
                )}
              </div>
            </div>
          </CardHeader>
          {selectedOrg.type === 'business' && (
            <CardContent>
              <div className="grid grid-cols-2 gap-4 text-sm">
                <div>
                  <span className="text-muted-foreground">Cross-Organization Default:</span>
                  <span className="ml-2 capitalize">
                    {selectedOrg.cross_org_default ? selectedOrg.cross_org_default?.replace('_', ' ') : 'None'}
                  </span>
                </div>
                <div>
                  <span className="text-muted-foreground">Created:</span>
                  <span className="ml-2">{new Date(selectedOrg.created_at).toLocaleDateString()}</span>
                </div>
              </div>
            </CardContent>
          )}
        </Card>

        <WorkspaceManagement
          orgId={selectedOrg.id}
          canManage={canManageOrg(selectedOrg.membership?.role ?? null)}
        />
      </div>
    )}

    {organizations.length === 0 && (
      <Card>
        <CardContent className="pt-6 text-center text-muted-foreground">
          No organizations found. This shouldn't happen - please contact support.
        </CardContent>
      </Card>
    )}

    <DeleteOrganizationDialog
      open={!!deletingOrg}
      onOpenChange={(open) => !open && setDeletingOrg(null)}
      organization={deletingOrg}
    />
  </div>
);
```

4. Move `useState` for `selectedOrgId` up beside the existing `useState` for `deletingOrg`.
5. Make sure imports include `useState` (already there) and `SelectionButton`.
