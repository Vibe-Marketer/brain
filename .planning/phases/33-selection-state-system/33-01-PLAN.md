# 33-01: SelectionButton Primitive

## Objective

Build the single canonical `<SelectionButton>` primitive at `src/components/ui/selection-button.tsx`. Every selection surface (sidebar, 2nd-pane workspace selector, settings tabs, call detail modal tabs, org cards) imports from this one component.

This is the foundational commit — must ship first so Phase 34 and downstream plans can consume it.

## Canonical Pattern (locked in CONTEXT.md)

- Vertical orange pill on the left edge (4px wide, 65% height, rounded)
- Gray rounded background highlight (`bg-muted`) on selected
- BOLD title text (not italic, not bold-italic — keep simple `font-bold`)
- Icon in rounded-square container (`w-8 h-8 rounded-md`) with an orange ring (`ring-2 ring-vibe-orange`) when selected
- Icon container background: `bg-card` always (semantic token handles light=white / dark=black-ish)
- Optional secondary description line below title (used by org cards)
- Click target = whole button
- Polymorphic render: `button` (default), `a`, or `div` (e.g., for sortable items)
- Optional `size` variant: `sm` (sidebar) vs `md` (org cards)

## Component API (locked)

```tsx
import { SelectionButton } from '@/components/ui/selection-button';

<SelectionButton
  selected={isActive}
  icon={<RiPhoneLine className="h-4 w-4" />}
  iconActive={<RiPhoneFill className="h-4 w-4" />}  // optional — falls back to icon
  label="Calls"
  description="Your call library"  // optional
  size="sm"  // 'sm' | 'md', default 'md'
  onClick={() => navigate('/')}
  showChevron  // optional, default false — for nav rows
  as="button"  // 'button' | 'a' | 'div', default 'button'
/>
```

Use `cva` (class-variance-authority) for variant composition, matching the pattern of `src/components/ui/button.tsx`.
