# 33-04: Migrate Call Detail Modal Tabs to Canonical Pattern (VIS-04)

## Objective

Replace the Radix-based `<TabsList>` / `<TabsTrigger>` orange-underline-pill in `CallDetailDialog.tsx` (Overview / Transcript / Invitees / Participants) with a row of `<SelectionButton as="button">` instances that drive the same tab state.

## Important Constraints

- Radix `<Tabs.Root>` provides state management (`value`, `onValueChange`). Keep it. Only the `<TabsList>` + `<TabsTrigger>` visuals are replaced.
- The four tabs are: Overview, Transcript, Invitees, Participants. Each has an icon already established in v1; if not present we'll add Remix Icons:
  - Overview → `RiInformationLine`
  - Transcript → `RiFileTextLine`
  - Invitees → `RiCalendarEventLine`
  - Participants → `RiGroupLine`
- These tabs sit at the TOP of the modal in a horizontal row. The canonical pattern is **vertical** (orange pill on left edge, icon to the left of title). Horizontal tabs would need the pill on the BOTTOM edge. **Per CONTEXT.md: same canonical pattern. So tabs become a vertical-row layout? No — pragmatically, the tabs MUST stay horizontal in a modal header.**
- **Decision (refines CONTEXT.md):** in a horizontal context, the canonical pattern is re-oriented: pill on the bottom edge (still orange, still 65% width centered), gray bg on selected tab, bold text, orange ring around icon. Use the SelectionButton with a new `orientation` variant or just inline the override via className.
- Simpler decision: render each tab as a regular `<SelectionButton>` in a vertical-style row… NO, that's a different UX. The CONTEXT.md "consistency" requirement is that the canonical visual identity (orange + ring + bold + bg-muted) is preserved, not necessarily the pill-side. Horizontal tabs = pill on bottom; vertical lists = pill on left. The visual cohesion is via the OTHER three indicators (gray bg, ring, bold).

**Final decision for this plan:** Use a SelectionButton-derived horizontal-tab variant. Implement by extending SelectionButton's cva with an `orientation: 'vertical' | 'horizontal'` variant where horizontal places the pill on the bottom (`before:bottom-1` and `before:left-1/2 before:-translate-x-1/2 before:w-[65%] before:h-1`). If extending the primitive is too invasive, inline the variant in this file with a TabSelectionButton local helper that mirrors SelectionButton's classes.
