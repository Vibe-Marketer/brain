  <files>src/lib/reporter-comms-filter.ts, src/lib/__tests__/reporter-comms-filter.test.ts, /Users/admin/dev/autopilot/src/lib/reporter-comms-filter.ts, /Users/admin/dev/autopilot/src/lib/reporter-comms-filter.test.ts</files>
  <behavior>
    Export `sanitizeReporterSummary(raw: string): { ok: boolean; text: string; redactions: string[] }` and the exported constant `FALLBACK_COPY = "This has been fixed and verified in the live app. Thanks for reporting it."`.

    Default-deny semantics (D-02): the function is an allowlist gate, not a search-and-replace. If ANY reject rule fires, return `{ ok: false, text: FALLBACK_COPY, redactions: [<rule names that fired>] }`. Only when zero reject rules fire AND the text passes the plain-English allowlist does it return `{ ok: true, text: <trimmed raw>, redactions: [] }`.

    Reject rules (each contributes a named entry to redactions when it fires):
    - file_path: POSIX absolute/relative paths — `/Users/...`, leading `src/`, `supabase/functions/`, segments like `foo/bar.ts`, and `*.ts:<line>` frame refs.
    - sha: 7–40 hex chars, especially near `commit`/`sha`/`merged` or inside backticks.
    - stack_trace: code fences (```), `Error:`/`TypeError:`/`ReferenceError:`, `at <fn> (...)`, line:col frames, ANSI escapes.
    - code_formatting: any backtick or fenced block.
    - banned_term: case-insensitive match of any of: agent, Autopilot, Codex, Claude, LLM, model, prompt, token, runner, worktree, branch, diff, push-gate, Sentry, stack, trace, deploy SHA, AI-powered.

    Allowlist (must ALSO pass for ok=true): non-empty after trim; length ≤ 280; only plain sentence characters (letters, digits, spaces, and . , ! ? ' " ( ) : ; - ); no newlines beyond a single space-join.

    Cases (assert in both repos):
    - sanitize("This has been fixed and verified in the live app.") → { ok: true }.
    - sanitize("Fixed in src/lib/foo.ts:42") → ok:false, fallback, redactions includes "file_path".
    - sanitize("Merged commit a1b2c3d4e5f6") → ok:false, redactions includes "sha".
    - sanitize("TypeError: x is not a function\n  at run (/Users/a/b.ts:1:1)") → ok:false, redactions includes "stack_trace".
    - sanitize("The agent fixed it") and sanitize("Autopilot resolved this") → ok:false, redactions includes "banned_term".
    - sanitize("```ts\nconst x=1\n```") → ok:false, redactions includes "code_formatting".
    - sanitize("") → ok:false (fails allowlist non-empty), text = FALLBACK_COPY.
    - On every ok:false case, text === FALLBACK_COPY exactly (no partial leak).
  </behavior>
