### Task 1: Create `_shared/html-escape.ts`
- New file: `supabase/functions/_shared/html-escape.ts`

### Task 2: Magic-byte validation in file-upload-transcribe
- File: `supabase/functions/file-upload-transcribe/index.ts`
- After MIME type check, read first 12 bytes of file
- Validate against known magic bytes:
  - MP3: `0xFF 0xFB` or `0xFF 0xF3` or `0xFF 0xF2` or ID3 tag `0x49 0x44 0x33`
  - WAV: `RIFF` (bytes 0-3)
  - MP4/M4A: `ftyp` at offset 4-7
  - MOV: `ftyp` at offset 4-7 (same as MP4)
  - WebM: `0x1A 0x45 0xDF 0xA3` (EBML header)
- Reject with 400 if magic bytes don't match claimed MIME type

### Task 3: Email XSS escape in send-org-invite

- Plain text version doesn't need escaping (no HTML context)
