# Plan 35-03 — Source Filter Popover Layout Fix

## Scope

**FILTER-04** — Source filter popover:

1. Apply/Clear buttons must fit fully within the popover.
2. The second row of source pills must be visible without requiring hover.

## Files

- `src/components/transcript-library/SourceFilterPopover.tsx` — only file in scope.

## Implementation

Current popover: `w-56` width; vertical list of checkboxes; footer with Apply/Clear that may clip.

### Edits

1. Increase popover width: `w-56` → `w-64`.
2. Add `max-h-[280px] overflow-y-auto` to the source list wrapper so the footer is always reachable:
   ```tsx
   <div className="px-4 pb-3 space-y-3 max-h-[280px] overflow-y-auto">
   ```
3. Ensure footer is stable / non-shrinking:
   ```tsx
   <div className="border-t p-3 flex flex-wrap justify-end gap-2 shrink-0">
   ```
4. Add `shrink-0` to both `<Button>` elements so they never get squeezed.

## Test Strategy

- `npm run build` must pass.
- Dev-browser: open Source filter popover with 4+ sources. Confirm all rows reachable via scroll without hover; Apply + Clear fully visible inside the popover.
