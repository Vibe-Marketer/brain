# Plan 35-01 — Table Column Cleanup

## Scope

Clean up the 3rd-pane recording table:

- **TABLE-01** — Remove the "Shared" column (header + cells + visibility option + sharingStatuses/accessLevels plumbing).
- **TABLE-02** — Verify the "Folders" column populates for all calls after Phase 30's UUID fix. Phase 30 (`passed` 2026-05-12) shipped a dual-key folder-assignment fallback in `TranscriptTable.tsx` (lines 351-357). This plan is verification-only — no code change expected.
- **TABLE-03** — Standardize column alignment: left for text columns, right/center for numeric. Header alignment matches cell alignment.

## Files

- `src/components/transcript-library/TranscriptTable.tsx` — column header definitions, `workspaceColumnOptions`, `homeColumnOptions`
- `src/components/transcript-library/TranscriptTableRow.tsx` — cell renderers
- `src/components/transcripts/TranscriptsTab.tsx` (if it passes `sharingStatuses` / `accessLevels`)

## Implementation

### TABLE-01 — Remove "Shared" column

**TranscriptTable.tsx:**

1. Delete `{ id: "sharedWith", label: "Shared With" }` from `workspaceColumnOptions` and `homeColumnOptions`.
2. Delete the `<TableHead>` block for `visibleColumns.sharedWith`.
3. Drop the `sharingStatuses` and `accessLevels` props from the `TranscriptTable` interface, defaults, and propagation to `TranscriptTableRow`.

**TranscriptTableRow.tsx:**

1. Delete the `<TableCell>` for `visibleColumns.sharedWith`.
2. Remove `sharingStatus` and `accessLevel` props.
3. Remove `SharedWithIndicator` import; remove `SharingStatus`, `AccessLevel` type imports.

**Callers:**

1. Stop passing `sharingStatuses` / `accessLevels` to `<TranscriptTable>`. `git grep "sharingStatuses=" src/` to find call sites.

### TABLE-02 — Verify Folders column

1. Confirm `TranscriptTable.tsx` lines 351-357 still has the Phase-30 dual-key fallback.
2. Verify column header + row cell render folder badges.
3. No code change. Capture dev-browser screenshot showing Folders badges on at least one Fathom call and one Zoom call.

| Column | Type | Header | Cell |
|---|---|---|---|
| TITLE | text | left | left |
| DATE | date | left | left (existing custom layout untouched) |

3. Audit headers/cells for any leftover `text-center` on text columns — switch to default (left).
