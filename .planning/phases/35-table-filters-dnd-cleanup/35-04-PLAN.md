# Plan 35-04 — Contacts Filter Queries Full Contacts DB

## Scope

**FILTER-03** — The Contacts filter currently queries `call_participants` (invitees / attendees from synced calls only). Switch to the **full org-scoped `contacts` table** so searching "Phill" returns Phill Tomlinson even if he hasn't been an invitee on any synced call.

## Files

- `src/components/transcript-library/FilterBar.tsx` — replace the `call_participants` query with a `contacts` query
- `src/components/transcripts/TranscriptsTab.tsx` — verify `filters.participants` consumption is email-based (no change needed if so)

## Implementation

### FilterBar.tsx — swap the data source

Replace the `allContacts` `useQuery` block (lines 67-97) with a `contacts` query:

```ts
const { data: allContacts = [] } = useQuery({
  queryKey: ["filter-bar-contacts", activeOrganizationId],
  queryFn: async () => {
    if (!activeOrganizationId) return [];

    const { data, error: fetchError } = await supabase
      .from("contacts")
      .select("email, name, display_name")
      .eq("org_id", activeOrganizationId)
      .not("email", "is", null)
      .order("name", { ascending: true, nullsFirst: false })
      .limit(1000);

    if (fetchError) {
      logger.error("Error fetching contacts for filter", fetchError);
      return [];
    }

    const map = new Map<string, string | null>();
    (data ?? []).forEach((row: { email?: string | null; name?: string | null; display_name?: string | null }) => {
      if (!row.email) return;
      const labelled = row.name ?? row.display_name ?? null;
      if (!map.has(row.email)) {
        map.set(row.email, labelled);
      } else if (labelled && !map.get(row.email)) {
        map.set(row.email, labelled);
      }
    });

    return Array.from(map.entries())
      .map(([email, name]) => ({ email, name }))
      .sort((a, b) => (a.name || a.email).localeCompare(b.name || b.email));
  },
  enabled: !!activeOrganizationId,
  staleTime: 5 * 60 * 1000,
});
```

Update the audit comment at the top of `FilterBar.tsx` lines 1-7: change "Contacts: inline query in FilterBar → .eq('organization_id', activeOrganizationId) ✓" to reference `contacts` table.

### Schema confirmation

The `contacts` table is keyed by `org_id` (confirmed via `src/hooks/useContacts.ts`). Columns: `id, org_id, user_id, name, email, ...`. If TypeScript Supabase types don't include `display_name`, drop it from the SELECT and the row type.

### TranscriptsTab.tsx — verify consumption unchanged

`filters.participants` is an `email[]`. The downstream filter matches `call.calendar_invitees` against those emails. Only the *set of choices* changes; the filter application is identical. Run `git grep "filters.participants" src/` to confirm the consumer's email-based logic.
