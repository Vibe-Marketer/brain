<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> save-pasted-transcript | Untrusted transcript text, metadata, and source hints cross into the backend parser |
| save-pasted-transcript -> parser helpers | Format inference decides whether structured data is trusted or preserved as raw |
| parser helpers -> runPipeline/database | Normalized transcript segments and metadata become durable recording data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | `save-pasted-transcript/index.ts` parser dispatch | mitigate | Keep D-01 raw fallback and preserve `full_transcript` when structure is partial so malformed inputs cannot destroy user content. |
| T-01-02 | Spoofing | Speaker extraction in parser helpers | mitigate | Enforce D-02 `Unknown Speaker` fallback and forbid attendee/header inference that fabricates identities. |
| T-01-03 | Integrity | Timestamp normalization | mitigate | Preserve source timestamps when present and use deterministic sequential offsets per D-03 so ordering stays stable. |
| T-01-04 | Repudiation | Source attribution for Loom/Markdown/manual inputs | mitigate | Preserve explicit `source_app`/source metadata paths in `save-pasted-transcript` and do not collapse Loom or Markdown into undocumented generic handling. |
| T-01-05 | Denial of Service | Parser exceptions on malformed transcript text | mitigate | Convert empty-segment/weak-format failures into raw fallback responses instead of thrown parse crashes for supported Phase 1 formats. |
</threat_model>
