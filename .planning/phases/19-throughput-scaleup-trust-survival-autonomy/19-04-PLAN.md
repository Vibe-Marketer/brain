## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Supabase trust state -> merge authority | DB ladder rows influence whether Autopilot can merge without per-fix admin approval |
| Autopilot daemon -> Git merge/push | Service process executes merge mechanics on behalf of approved candidates |
| metrics freshness -> auto-demotion | Stale or failed metric reads could over-grant authority if not fail-closed |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-19-15 | Spoofing | auto approval events | mitigate | Use distinct system trust events; never forge admin `approval` events or actor IDs. |
| T-19-16 | Tampering | merge path | mitigate | Preserve rebase, repro replay, deterministic gate, ff-only merge, and deploy verification order. |
| T-19-17 | Repudiation | auto-demotion | mitigate | Write trust event metadata when survival drop causes demotion. |
| T-19-SC | Tampering | package installs | accept | No new packages. |
