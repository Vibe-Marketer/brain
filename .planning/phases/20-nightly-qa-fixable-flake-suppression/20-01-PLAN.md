<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Autopilot daemon -> Supabase RPC | Service-role runtime submits untrusted crawler findings to DB-owned ingestion. |
| Browser admin UI -> qa_findings reads | Authenticated users request review-lane data through RLS-gated tables. |
| Crawler output -> ticket evidence | Browser-observed strings become stored ticket messages and context. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Spoofing | `ingest_qa_ticket` | mitigate | Stamp `source='nightly_qa'` inside SECURITY DEFINER SQL; no source parameter. |
| T-20-02 | Tampering | `qa_findings` | mitigate | No browser write policies; service-role-only writes; admin SELECT only. |
| T-20-03 | Repudiation | `tickets` / `ticket_events` | mitigate | Write created and occurrence events with NULL system actor for every RPC path. |
| T-20-04 | Information Disclosure | `qa_findings` | mitigate | RLS admin-only SELECT; reporter_id NULL on QA tickets; no customer comms path. |
| T-20-05 | Denial of Service | fingerprint dedup | mitigate | DB partial unique index plus `ON CONFLICT` occurrence bump. |
| T-20-06 | Elevation of Privilege | RPC grants | mitigate | Revoke PUBLIC/anon/authenticated and grant EXECUTE only to service_role. |
| T-20-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this phase; package legitimacy audit says none. |
</threat_model>
