## Sampling Rate

- **After DB migration draft:** Run linked/local DB dependency scans for old/new column names, functions, views, constraints, and indexes.
- **After generated type refresh:** Run `npm run type-check`.
- **After source/test/doc rename:** Run focused tests that cover ID translation, Fathom refresh, share links, folder/sync behavior, and global search where available.
- **Before `$gsd-verify-work`:** `npm run type-check` and `npm run build` must be green, and exact-string scans must show no active-code `legacy_recording_id` references.
- **Max feedback latency:** One task boundary; do not defer type/build failures to final verification.
