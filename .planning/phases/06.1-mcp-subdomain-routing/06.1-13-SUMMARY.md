# 06.1-13 Summary: OAuth Consent Subdomain Pre-Scoping

## Implemented

- Updated `OAuthConsentPage` to derive an org slug from `authDetails.resource`, falling back to `authDetails.redirect_uri`.
- Pre-scoped subdomain consent now auto-locks the grant to the matching user organization and hides the organization picker.
- Added the connection URL row in the consent Client Details block for subdomain-origin flows.
- Added an explicit access error and disabled approval when the subdomain slug does not match any organization available to the signed-in user.
- Preserved the legacy picker flow when no subdomain slug is present.
- Added `organizations.slug` to the frontend organization query/types so the consent page can resolve the slug locally.
- Added source-contract auth slug tests covering org/workspace header handling, `org_not_found`, `token_org_mismatch`, workspace mismatch, legacy no-header behavior, and org-token workspace narrowing.
