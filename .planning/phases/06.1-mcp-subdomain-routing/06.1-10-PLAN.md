<objective>
Audit all MCP tool handlers in `supabase/functions/mcp-server/tools/` to verify org_id boundary enforcement per ISC-51–56. Fix any tools missing the org_id filter. Specifically: list_shared_calls, get_contact_calls, get_speaker_calls, get_tagged_calls (cross-workspace queries must be org-scoped), create_organization (per-user org limit), import_youtube_video (SSRF validation).

Purpose: Org-scoped tokens access all workspaces within an org. Cross-workspace queries (contacts, speakers, shared calls, tags) must enforce org_id boundary to prevent cross-org data access. ISC-51–56 (MEDIUM security gate, required before GA).

Output: All named tool handlers verified and fixed to enforce org_id boundary. create_organization enforces max 5 orgs per non-admin user. import_youtube_video validates URL with regex before forwarding.
</objective>

<threat_model>
**ASVS Level:** L1

**Threats addressed by this plan:**
- [T-06.1-TOOL-01]: Unauthorized Access — Cross-org data access via tool calls. Org-scoped token queries contacts/speakers/tags across all workspaces without org_id boundary. User in Org A can access Org B data by crafting tool calls. Mitigation: all cross-workspace queries filter by org_id (ISC-51–53).
- [T-06.1-TOOL-02]: Denial of Service — Org flooding. User creates unlimited orgs to exhaust system resources. Mitigation: max 5 orgs per non-admin user enforced in create_organization (ISC-54).
- [T-06.1-SSRF-01]: SSRF — import_youtube_video forwards arbitrary URLs to youtube-import function. Attacker submits internal network URL. Mitigation: regex validation rejects non-YouTube URLs before forwarding (ISC-55).

**Residual risks:** The org limit (5) is hardcoded per ISC-54. Adjust via admin tooling if needed.

**Block condition:** MEDIUM severity per execution plan. Does not block DNS provisioning but should complete before GA.
</threat_model>
