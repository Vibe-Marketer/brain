<objective>
Remove the `readClientIdFromJwt()` function from `supabase/functions/mcp-server/auth.ts` and replace raw base64 JWT decoding with extraction of `client_id` from the verified user object returned by `authClient.auth.getUser(rawToken)`.

Purpose: `readClientIdFromJwt()` decodes the JWT payload without signature verification — any attacker who can construct a JWT with an arbitrary `client_id` claim can pivot to a different client's grant row. This is ISC-8–12 (CRITICAL security gate).

Output: Modified `auth.ts` with `readClientIdFromJwt` deleted, `client_id` sourced exclusively from `jwtUser.app_metadata`.
</objective>

- [T-06.1-JWT-01]: Spoofing / Tampering — JWT grant scope pivoting. Attacker forges client_id claim in base64-encoded JWT payload (no sig verification in readClientIdFromJwt).
