## Decisions Made

- **Cloudflare Free plan constraints**: The Cloudflare API rejected period=60 (only period=10 allowed on Free), rejected `matches` regex operator (requires Advanced Rate Limiting), and rejected mitigation_timeout != 10. Adapted to 5 req/10s = 30 req/min which is stricter than the ISC-46 goal of 20 req/min. Rule runs in `block` mode directly (Free plan doesn't expose simulate mode via Ruleset API).
- **expression="true"**: Free plan doesn't support regex matching against hostnames in rate limit rules. The zone itself is `callvaultai.com` so all traffic through the zone is callvaultai.com traffic — `expression="true"` correctly catches all zone traffic.
- **100ms delay is a floor**: The `uniformNotFound()` function always applies the full 100ms delay in this skeleton. The worker-routing plan should convert this to `Promise.race([delay, upstream])` so the delay only adds latency when the upstream responds faster than 100ms.
