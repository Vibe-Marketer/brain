# Phase 06.1 Plan 11: Slug Schema Summary

Added and live-applied org/workspace slug schema for MCP subdomain routing.

## What Was Built

- Added `organizations.slug` and `workspaces.slug` as `VARCHAR(40)` with `^[a-z0-9]+$` format checks.
- Backfilled all existing orgs and workspaces with generated lowercase alphanumeric slugs.
- Enforced `NOT NULL`, global org slug uniqueness, and per-org workspace slug uniqueness.
- Wired delete tombstone triggers for orgs and workspaces.
- Added insert/update tombstone rejection triggers so retired slugs cannot be reused.
- Added workspace combined-host-label length guard for `{orgSlug}-{workspaceSlug}`.
