<threat_model>
**ASVS Level:** L1

**Threats addressed by this plan:**
- [T-06.1-ENUM-01]: Information Disclosure — Slug enumeration via response body differentiation. Attacker probes *.callvaultai.com to determine which slugs are valid. Different 404 bodies for "unknown" vs "valid but unauthed" leak information. Mitigation: uniform {"error":"not_found"} body for all non-routable paths (ISC-44–45).
- [T-06.1-ENUM-02]: Information Disclosure — Timing oracle for slug existence. Valid-slug paths take longer (DB lookup) than invalid-slug paths (format reject). Mitigation: 100ms floor on 404 responses collapses timing differential (ISC-47).
- [T-06.1-ENUM-03]: Information Disclosure / DoS — High-volume slug enumeration exhausts DB resources. Attacker sends thousands of requests per minute to enumerate all possible slugs. Mitigation: Cloudflare rate limit rule (20 req/min/IP) blocks enumeration at CDN tier before requests reach origin (ISC-46). Configured in Task 2 blocking checkpoint — not just a code comment.

**Residual risks:** Rate limit rule starts in "simulate" mode — switch to "ban" after confirming no false positives in production traffic.

**Block condition:** MEDIUM severity — does not block DNS provisioning per D-03, but should complete before public launch.
</threat_model>
