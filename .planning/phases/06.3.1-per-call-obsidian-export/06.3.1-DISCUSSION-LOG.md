## Output Shape

| Option | Description | Selected |
|--------|-------------|----------|
| Single `.md` file | Download one standalone Obsidian-compatible markdown note for the current call. | ✓ |
| ZIP folder tree | Package the single note inside the full `CallVault/{org}/{workspace}/` ZIP structure. | |
| Copy-only | Only copy markdown to clipboard, with no file download. | |

**User's choice:** Use the recommended default.
**Notes:** The per-call flow should not wrap a single note in a ZIP. `vault_path` can still describe the recommended Obsidian destination path.
