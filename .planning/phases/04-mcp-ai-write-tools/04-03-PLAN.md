<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| MCP params -> existing recording | Follow-up tools mutate already-created recording data |
| Caller intent -> destructive behavior | Replace/delete semantics must never be inferred from missing fields |
| Speaker names -> participant identity | Name-only identity data can collide across people |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-03-01 | Tampering | append_to_transcript | mitigate | Append by default and preserve existing `full_transcript`. |
| T-04-03-02 | Tampering | update_call_metadata | mitigate | Merge only supplied fields and preserve existing `source_metadata`. |
| T-04-03-03 | Elevation of Privilege | all follow-up tools | mitigate | Verify recording access before mutation. |
| T-04-03-04 | Spoofing | set_speakers | mitigate | Resolve by email/full-name tiers and report ambiguous names instead of guessing. |
</threat_model>
