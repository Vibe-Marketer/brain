CallVault lets you export call content in several formats so you can share it outside the platform, archive it, or bring it into other tools.

## Export formats

<CardGroup cols={3}>
  <Card title="Markdown" icon="file-code">
    Plain text with Markdown formatting. Works well with Notion, Confluence, GitHub, Obsidian, or any tool that renders Markdown.
  </Card>
  <Card title="Text" icon="file-lines">
    Plain text with no formatting. Use when you need raw content without any markup.
  </Card>
  <Card title="PDF" icon="file-pdf">
    A clean, formatted document with call metadata, AI summary, and full transcript. Ideal for sharing with stakeholders.
  </Card>
  <Card title="Word (.docx)" icon="file-word">
    Editable Word document with the same content as the PDF. Use when the recipient needs to edit or annotate the content.
  </Card>
  <Card title="JSON" icon="brackets-curly">
    Structured data export with all call metadata, transcript, and summary. Useful for data pipelines or custom integrations.
  </Card>
  <Card title="CSV" icon="file-csv">
    Tabular data export with call metadata. Use for analysis in spreadsheets or importing into other tools.
  </Card>
</CardGroup>

## Exporting calls

1. Select one or more calls using the checkboxes in the call list
2. Click **Export** in the action bar
3. The export dialog opens with options for organizing and formatting your export

## Choosing what to include

When exporting, toggle which sections appear in the exported documents:

| Section | What it includes |
|---|---|
| **Meeting summaries** | AI-generated overview, key topics, and action items |
| **Full transcripts** | The complete timestamped transcript with speaker labels |
| **Participant info** | Calendar invitees, recorded-by name and email |
| **Timestamps & URLs** | Recording start/end times and source URL |

All four sections are included by default. Uncheck any section to exclude it.

## Organizing your export

Choose how CallVault structures the export files:

| Organization | Output | Best for |
|---|---|---|
| **Single bundle** | One combined file with all calls | Sharing a single document or LLM context |
| **Individual files** | One file per call, packaged in a ZIP | Archiving or importing into other tools |
| **Weekly bundles** | Files grouped by week in ZIP folders | Time-based review or weekly summaries |
| **By folder** | Files grouped by their folder assignment | Matching your existing organizational structure |
| **By tag** | Files grouped by tag | Filtering exports by topic or category |

<Note>
  Weekly bundles, by-folder, and by-tag organization only support Markdown and Text formats. Single bundle and individual files support all six formats.
</Note>

## AI meta-summary

When exporting multiple calls, you can enable **Generate AI Meta-Summary** to create a separate executive summary document that analyzes patterns across all selected calls. The meta-summary includes:

- **Executive summary** — high-level overview across all calls
- **Key themes** — common topics that appeared across calls
- **Key decisions** — decisions that were made
- **Action items** — consolidated list of action items
- **Notable insights** — patterns or standout observations
- **Participant highlights** — key contributions per participant
- **Timeline summary** — chronological overview of events

The meta-summary is saved as a separate Markdown file alongside your export.

<Note>
  Generating an AI meta-summary counts as one AI action toward your plan's monthly limit.
</Note>

## Export preview

Before exporting, the dialog shows a preview panel with:

- **Date range** — the earliest and latest call dates in your selection
- **Unique participants** — how many distinct people appear across the selected calls
- **Estimated tokens** — approximate token count (shown when full transcripts are included)
- **Output format** — a description of what the export will produce (e.g., "ZIP with 12 individual MD files")

## Sharing vs. exporting

If you want to share a call with someone outside CallVault, a shareable link is often better than an export — recipients can read the transcript without needing to open a document. See [Sharing](/transcripts/sharing).

Use export when you need a permanent, offline copy, when the recipient needs to edit the content, or when you want to feed call data into another tool.
