## April 6, 2025

### People page

There's a new **People** page in the sidebar where you can manage contacts, organization members, and pending invites — all in one place. Browse your contact list, see who's in your org, and check outstanding invitations without jumping between settings screens.

See [Inviting Members](/collaboration/inviting-members) for details on managing your team.

### Shared With Me

Calls shared with you now appear in a dedicated **Shared With Me** section in the sidebar. No more hunting through workspaces to find calls someone sent your way.

See [Sharing](/transcripts/sharing) for how sharing works.

### Drag and drop in the sidebar

You can now drag calls directly onto workspaces and folders in the sidebar to move them. This makes organizing your call library faster and more intuitive.

See [Folders](/core-concepts/folders) for more on organizing calls.

### Organization management page

A new **Organization** page in the sidebar gives admins a dedicated space to manage org-level settings, including renaming, member overview, and role management — without navigating through nested settings tabs.

See [Organization Settings](/settings/organization-settings) for the full list of options.

### Redesigned account settings

Your account settings page has been rebuilt with a cleaner layout — profile, notifications, security, and preferences are now organized into clearly separated sections.

See [Account Settings](/settings/account-settings) for what's available.

### Redesigned login screen

The sign-in page has a fresh, modern look that's faster to load and easier to use.

### Contact autocomplete in invites

When inviting someone to a workspace, you can now search by name and CallVault will autocomplete from your contacts list.

### Simpler routing rules

Routing rules are now independent — no more priority ordering. Each rule runs on its own, and you can delete individual rules directly. This makes the rules easier to manage, especially as your list grows.

See [Routing Rules](/automation/routing-rules) for the updated workflow.

### Streamlined invite dialog

The workspace invite dialog now shows the invite link and email form on the same page (no more switching tabs). You can also see the link status and rotate it if needed.

### OAuth flows open in a new tab

Connecting integrations like Fathom and Zoom now opens the authorization flow in a new tab, so you don't lose your place in CallVault.

### Search improvements

Filters and search now check all records in your workspace, not just the current page. Results are more complete and consistent.

### Bug fixes

- **Fathom sync reliability** — resolved several issues that could cause Fathom imports to fail or report false failures.
- **Failed import titles** — failed imports now display the correct call title instead of a generic label.
- **Workspace deletion** — fixed an issue that could prevent workspace deletion in certain configurations.
- **Routing rule bulk apply** — fixed a bug where bulk-applying routing rules could skip some calls.
- **Date picker styling** — the date range picker now displays correctly in all themes.

## What's new

### Workspace routing rules

You can now create routing rules to automatically organize incoming calls into the right workspace and folder — no manual sorting required. Set conditions based on meeting title, participant name, duration, or call source, and define actions like tagging or folder assignment.

See [Routing Rules](/automation/routing-rules) for setup instructions.

### Teams

Added support for Teams — named groups of organization members that can be added to workspaces together. Manage access for your whole sales team or CS team in one place instead of member-by-member.

See [Teams](/collaboration/teams) to get started.

### Bulk export

You can now select multiple calls in a list view and export them all at once. Bulk exports download as a ZIP file containing one document per call. CSV bulk export produces a single file with all calls combined.

See [Export](/transcripts/export) for format options.

### Share link improvements

Share links now support password protection and configurable expiry dates. Existing share links continue to work unchanged.

See [Sharing](/transcripts/sharing) for the updated options.

### AI summary regeneration

If a transcript was re-run or corrected, you can now regenerate the AI summary for any call from the **⋯** menu in the summary panel.
