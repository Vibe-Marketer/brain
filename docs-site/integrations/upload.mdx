<Note>
  **CallVault does not currently have a "upload an audio or video file and transcribe it" feature.** There is no place in the product to drop an MP3, MP4, or other recording file for CallVault to transcribe. If you're looking for that flow, use one of the options below instead.
</Note>

## If you have an audio or video recording

Connect the source that produced it so CallVault can transcribe it for you:

- [Fathom](/integrations/fathom) or [Zoom](/integrations/zoom) — connect your account and CallVault imports and transcribes recordings automatically
- Any other supported connector — [Fireflies](/integrations/fireflies), [Read.ai](/integrations/readai), [Grain](/integrations/grain), or [Plaud](/integrations/plaud)

If none of those fit, transcribe the recording with a tool of your choice, then bring in the resulting transcript text using the option below.

## If you already have a transcript

Use **Import Transcript** — paste transcript text, or upload a transcript file you already have (VTT, SRT, TXT, or Markdown, up to 10MB). CallVault parses it, generates an AI summary, and adds it to your call list.

1. Go to **Import** in the sidebar
2. Select **Import Transcript** from the source list
3. Paste the transcript text, or click **Choose transcript file** to upload it
4. Confirm the destination workspace and click **Import Transcript**

See [Paste a Transcript](/integrations/paste-transcript) for the full walkthrough, including supported source links, live parsing preview, and format details.
